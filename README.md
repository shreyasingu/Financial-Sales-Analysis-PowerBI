# Financial Sales Analysis Dashboard | Power BI

## 📊 Project Overview

The Financial Sales Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI.

The objective of this project is to analyze financial sales data and provide meaningful insights into sales performance, profitability, discounts, countries, products, segments, and monthly trends.

The dashboard helps users understand business performance through interactive visualizations, KPIs, filters, and analytical charts.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Analyze average profit
- Analyze discount values
- Compare sales across countries
- Compare sales across products
- Analyze monthly profit trends
- Analyze sales and profit geographically
- Analyze performance by country, segment, and product
- Create an interactive and user-friendly Power BI dashboard
- Convert raw financial data into meaningful business insights

## 📌 Key KPIs

The dashboard contains the following key performance indicators:

### Total Sales
Displays the overall sales generated from the dataset.

### Average Profit
Shows the average profit generated from the sales transactions.

### Maximum Discount
Displays the highest discount value available in the dataset.

---

## 📊 Dashboard Visualizations

### 1. Sales by Country and Product

A stacked bar chart is used to compare sales across different countries and products.

This visualization helps identify how different products contribute to sales in each country.

---

### 2. Average Profit by Month

A line chart is used to analyze the average profit across different months.

This helps identify changes and trends in profitability throughout the year.

---

### 3. Sales and Profit by Country

A map visualization is used to display sales and profit geographically.

This helps understand the performance of different countries.

---

### 4. Country, Segment and Product Analysis

An interactive analytical visual is used to drill down from:

Country → Segment → Product

This allows users to explore detailed performance at different levels.

---

### 5. Interactive Filters

The dashboard provides interactive filtering capabilities.

Users can filter the analysis based on different dimensions such as:

- Country
- Product
- Segment

These filters allow users to interactively explore the data.

## 🔄 Data Analysis Process

The project followed the following process:

### Step 1 – Data Collection

The financial sales dataset was imported into Power BI.

### Step 2 – Data Cleaning

The data was reviewed and prepared using Power Query.

The cleaning process included:

- Checking column names
- Checking data types
- Removing unnecessary data
- Handling missing values where required
- Preparing data for analysis

### Step 3 – Data Transformation

The dataset was transformed into a suitable structure for analysis and visualization.

### Step 4 – Data Modeling

The required fields and relationships were prepared for reporting.

### Step 5 – DAX Analysis

DAX calculations were used to create measures and perform calculations such as:

- Total Sales
- Average Profit
- Maximum Discount

### Step 6 – Visualization

Different Power BI visualizations were created to analyze:

- Sales
- Profit
- Countries
- Products
- Segments
- Monthly trends

### Step 7 – Dashboard Design

The visualizations were arranged into a single interactive dashboard with KPI cards, charts, maps, filters, and analytical visuals.
